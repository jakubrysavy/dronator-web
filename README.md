# Dronator

Personal website of the **Dronator** YouTube channel, a project focused on drone footage, primarily of nature. It features video showcases, an author profile and contact details.

🌐 Website: https://dronator.cz
▶️ YouTube: https://www.youtube.com/@Dronatorcz

> Drone first!

## About

Dronator is a personal project dedicated to aerial footage of nature, from forests and quarries to coastlines and landscapes in the Czech Republic and the Baltics. The author has been flying DJI drones since 2024 and holds an A2 certificate issued by the Czech Civil Aviation Authority.

The website is a simple static showcase of the channel.

## Features

- Overview of YouTube videos
- Author profile
- Contact section
- Logo and favicon

## Repository Structure

| Path | Description |
|---|---|
| index.html | Main page of the website |
| videos.js | List of videos displayed on the site |
| img/ | Images, logo and profile photo |
| scripts/ | Helper scripts |
| .github/workflows/ | Automated deployment to GitHub Pages |
| CNAME | Custom domain dronator.cz |
| LICENSE | License terms |

## Deployment

The site is deployed automatically to GitHub Pages whenever changes are pushed to the main branch. The domain dronator.cz is pointed to GitHub through DNS records at Forpsi.

## Development

The website was built with the help of AI tools, based on the author's prompts and direction. All graphics, photographs and videos are created by the author.

To preview locally, open index.html in a web browser.
